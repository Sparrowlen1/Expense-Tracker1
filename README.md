# Sparrowlen Expense Tracker
A simple expense tracking app built with React and Vite. Add, search, and delete your daily expenses.
## live Demo
view live here: https://expense-tracker1-eta.vercel.app/

### features that it has
- Add expenses with name, category, amount, and date
- Search expenses by name or description
- Delete expenses with confirmation
- Form validation with error messages
- Responsive design for mobile and desktop

#### tech stack used
- React 18
- Vite
- Tailwind CSS
- React Icons

##### Clone the repository
git clone git@github.com:Sparrowlen1/Expense-Tracker1.git
###### install dependency
npm install
###### run develeopment server
npm run dev
